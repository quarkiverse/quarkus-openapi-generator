APIs are generated by default. To disable them set `generate-apis` to false:

[source,properties]
----
quarkus.openapi-generator.codegen.spec.my_openapi_yaml.generate-apis=false
----

[NOTE]
====
Disabling API generation does not disable the generation of the authentication classes
(`CompositeAuthenticationProvider` and `AuthenticationPropagationHeadersFactory`). If your
spec defines security schemes and you only want the models to be generated, you also need to
disable xref:authentication-support[security generation]:

[source,properties]
----
quarkus.openapi-generator.codegen.spec.my_openapi_yaml.enable-security-generation=false
----
====
